# Интерфейс

Расписание рассчитано на повседневную работу с таблицей занятий. Светлый фон, системный шрифт и небольшое число акцентов помогают различать данные, действия и статусы.

| Элемент | Значение |
| --- | --- |
| Фон | `#f3f6fa` |
| Поверхность | `#ffffff` |
| Основной текст | `#182d45` |
| Основное действие | `#225fb0` |
| Граница | `#dfe6ef` |
| Основной текст и поля | 16 px |
| Отступы | 8, 12, 16, 24, 32 px |

Статусы обозначены текстом и цветом. Ошибки используют role=alert, результаты операций — role=status. Поля имеют подписи, интерактивные элементы — видимый фокус. Внешних шрифтов нет; иконки выполнены inline SVG.

## Адаптивность

На широком экране используется боковое меню и недельная сетка. До 1250 px дни располагаются в три колонки, до 900 px меню переходит наверх. До 560 px календарь и формы становятся одноколоночными.

На телефоне прокручивается документ, без отдельной внутренней области формы и закреплённого нижнего меню. Размер полей 16 px предотвращает автоматическое увеличение страницы при вводе в iOS.

## Навигация и состояния

Разделы используют hash-маршруты: `#schedule`, `#editor`, `#directories`, `#profile`. Недоступный выбранной роли раздел заменяется расписанием. Несохранённые данные защищены подтверждением перед уходом.

Карточка занятия открывается внутри страницы. Фокус переходит к её заголовку, закрытие возвращает его к кнопке занятия. Диалог подтверждения сначала фокусирует безопасное действие; Escape отменяет переход.

Роль выбирается нативными radio-кнопками и применяется отдельным действием. Во время сохранения форма заблокирована. Если ответ потерян, приложение само сверяет профиль с сервером: совпадение подтверждает сохранение, несовпадение оставляет выбор в форме и предлагает повторить действие. Повторная запись автоматически не отправляется. Во время сверки показано «Проверяем сохранение…»; её результат доступен скринридеру. Ошибка загрузки расписания не отображается как отсутствие занятий.

Анимация не является частью сценариев; CSS учитывает prefers-reduced-motion.
